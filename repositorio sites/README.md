# Repositório de Sites

Portfólio de projetos web desenvolvidos com foco em design moderno, performance e experiência do usuário.

## 🚀 Projetos

### 1. Alencar & Prado - Advocacia
Site institucional para escritório de advocacia com design elegante e profissional.
- **Pasta:** `/sites/alencar-prado.html`
- **Características:** Layout corporativo, paleta dourado/navy, seções de áreas de atuação

### 2. Pão de Casa - Padaria Artesanal
Site comercial para padaria com integração WhatsApp e catálogo de produtos.
- **Pasta:** `/sites/pao-de-casa.html`
- **Características:** Fotografia gastronômica, paleta terrosa/quente, CTAs de conversão

### 3. Casa Lume - E-commerce
Loja virtual completa de artigos para casa e decoração.
- **Pasta:** `/sites/casa-lume.html`
- **Características:** Sistema de filtros, carrinho lateral, checkout integrado

## 📁 Estrutura

```
repositorio sites/
├── sites/              # Páginas dos projetos
├── css/               # Tailwind CSS compilado
├── src/assets/        # Imagens e recursos
├── index.html         # Landing page do portfólio
├── sites.html         # Listagem de projetos
└── robots.txt         # SEO
```

## 🛠️ Tecnologias

- HTML5 semântico
- Tailwind CSS v4.3.3
- JavaScript vanilla
- Design responsivo mobile-first

## 🌐 Deploy

Sites otimizados para hospedagem estática. Compatível com:
- GitHub Pages
- Vercel
- Netlify
- VibeDrop
